# 亚马逊竞品采集脚本 v2.0

> 采集亚马逊商品页面信息并同步到飞书多维表格或本地API

## 功能特性

- ✅ **双方案支持**：飞书多维表格直连 / 本地API服务
- ✅ **可视化配置**：内置配置页面，支持连接测试
- ✅ **全字段采集**：ASIN、标题、品牌、五点、描述、价格、评分、排名、图片
- ✅ **评论采集**：自动提取页面可见评论
- ✅ **当前变体**：只采集当前选中的变体信息
- ✅ **多站点支持**：US/UK/DE/FR/IT/ES/JP/CA/AU

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 Tampermonkey 图标 → 添加新脚本
3. 复制 `script.user.js` 内容粘贴
4. 保存脚本

## 使用说明

### 首次配置

1. 打开任意亚马逊商品页面
2. 点击右下角 🎯 按钮
3. 点击 ⚙️ 设置
4. 选择方案并填写配置信息
5. 点击 "测试连接" 验证
6. 保存配置

### 采集数据

1. 浏览亚马逊商品页面
2. 确认产品信息合适
3. 点击 🎯 采集 按钮
4. 核对/编辑数据
5. 点击 📤 提交采集

## 配置说明

### 方案一：飞书多维表格

需要配置：

| 配置项 | 说明 |
|-------|-----|
| App ID | 飞书应用的App ID |
| App Secret | 飞书应用的App Secret |
| 多维表格链接 | 完整的飞书表格URL（自动解析token） |

**飞书应用权限要求**：
- `bitable:app` - 多维表格读写权限

**多维表格字段**（建议）：

| 字段名 | 类型 | 说明 |
|-------|-----|-----|
| 本地SKU | 文本 | 手动填写，脚本会记忆 |
| ASIN | 文本 | |
| 站点 | 文本 | |
| 链接 | 超链接 | |
| 标题 | 文本 | |
| 品牌 | 文本 | |
| 五点1-6 | 文本 | 自动获取前6条 |
| 产品描述 | 文本 | 优先A+内容 |
| 评分 | 数字 | |
| 评论数 | 数字 | |
| BSR排名 | 超链接 | 排名 + 类目链接 |
| BSR小类目 | 超链接 | 小类目排名 + 链接 |
| 上架日期 | 文本 | |
| 评论内容 | 文本 | 前5-10条评论汇总 |
| 主图 | 文本 | 图片URL |
| 副图1-8 | 文本 | 图片URL |
| 采集时间 | 日期 | |

### 方案二：本地API

需要配置：

| 配置项 | 示例 |
|-------|-----|
| API地址 | `http://localhost:8000` |
| API端点 | `/api/v1/competitor/add` |

API需实现接收POST请求的端点，接收JSON格式的采集数据。

## 采集字段

根据数据结构规范，采集以下完整字段：

```yaml
ASIN: string
链接: string
站点: MarketCode
采集时间: ISO8601

标题: string
品牌: string
五点描述: string[]
产品描述: string


图片:
  主图: string
  副图1-8: string

销售排名:
  排名: number
  类目: string

评分: number
评论数: number
评论列表: Review[]
```

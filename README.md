# 亚马逊竞品采集脚本 v0.4.16

> 采集亚马逊商品页面信息并同步到飞书多维表格

## ✨ 功能特性

- ✅ **一键采集**：标题、品牌、五点描述、产品描述
- ✅ **BSR排名**：支持多语言站点BSR解析
- ✅ **上架日期**：自动转换为 YYYY/M/D 格式
- ✅ **图片采集**：主图 + 8张副图URL
- ✅ **A+截图**：一键截取A+内容并下载
- ✅ **飞书同步**：实时同步到飞书多维表格
- ✅ **折叠界面**：紧凑UI，支持折叠/展开
- ✅ **多站点**：US/UK/DE/FR/IT/ES/JP/CA/AU

## 📦 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开 [脚本安装地址](https://github.com/niudakok/auto-get-amz-listing/raw/refs/heads/main/script.user.js)
3. 在 Tampermonkey 安装页确认安装

新安装的脚本已配置 GitHub 更新源。已有脚本若是通过手动复制安装，请在 Tampermonkey 的脚本设置中将“更新 URL”设为：

```text
https://github.com/niudakok/auto-get-amz-listing/raw/refs/heads/main/script.user.js
```

保存后，点击“检查用户脚本的更新”即可拉取新版本；以后可从 Tampermonkey 检查更新，无需手动复制脚本。

> ⚠️ **刚发布新版本就检查更新，提示“已是最新版”？** 这是 GitHub Raw CDN 缓存导致的：新版本 push 后，CDN 节点会继续返回旧文件约 5 分钟，Tampermonkey 读到旧版本号便认为没有更新。**等 5~10 分钟后再点“检查更新”即可**，无需重装脚本。

## 🚀 快速开始

1. 打开任意亚马逊商品页面
2. 点击右下角 **🎯 采集** 按钮
3. 填写产品名称（必填）和本地SKU（选填）→ 点击 **📤 提交**

## 🔑 飞书多维表格配置

### 第一步：创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/app)
2. 点击 **创建企业自建应用**
3. 填写应用名称（如："亚马逊采集助手"）
4. 创建成功后进入应用详情页

### 第二步：获取凭证

1. 点击左侧 **凭证与基础信息**
2. 复制 **App ID** 和 **App Secret**

> ⚠️ App Secret 非常重要，请妥善保管！

### 第三步：配置权限

进入 **权限管理**，搜索并开启：
- `bitable:app` - 多维表格应用权限
- `bitable:app:readonly` - 读取多维表格
- `bitable:app:writable` - 写入多维表格

### 第四步：创建多维表格

1. 在飞书中创建多维表格
2. 复制表格链接，格式如：
   ```
   https://xxx.feishu.cn/base/xxxxxx?table=tblxxxxxx
   ```

### 第五步：授权应用

1. 打开多维表格
2. 点击右上角 **更多** → **添加文档应用**
3. 搜索并添加你创建的应用

### 第六步：脚本配置

1. 在亚马逊页面点击 **🎯 采集**
2. 点击 **⚙️ 设置**
3. 填写 App ID、App Secret、多维表格链接
4. 点击保存

## 📋 采集字段

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| 产品名称 | 文本 | 手动填写，脚本会记忆并写入同名字段 |
| 本地SKU | 单选 | 从飞书表格“本地SKU”列已有记录中读取选项，选填并写入同名字段 |
| ASIN | 文本 | 自动采集 |
| 站点 | 文本 | US/UK/DE等 |
| 标题 | 文本 | 商品标题 |
| title_differentiation | 文本 | 商品副标题；提交时若字段不存在会自动创建 |
| 品牌 | 文本 | 品牌名称 |
| 五点1-6 | 文本 | 五点描述 |
| 产品描述 | 文本 | 产品描述 |
| 评分 | 数字 | 商品评分 |
| 评论数 | 数字 | 评论数量 |
| BSR排名 | 超链接 | 排名+类目链接 |
| 上架日期 | 文本 | YYYY/M/D格式 |
| 主图片 | 附件 | 自动下载商品主图并上传为飞书附件 |
| 副图1-8 | 文本 | 图片URL |

> 本地SKU下拉框会优先显示本机缓存，并在后台从飞书刷新；新增SKU选项前，请先在飞书表格中添加一条包含该值的记录。
